# Installation PHP et environnement local

## 1. Vérifier la version de PHP

```bash
php -v
```

Cette commande permet de vérifier que PHP est correctement installé.

Version installée : PHP 8.5.12

## 2. Démarrer le serveur local

```bash
php -S localhost:8000
```

Cette commande permet de démarrer le serveur de développement local PHP.

## 3. Tester le serveur

Ouvrir l'adresse suivante dans le navigateur :

http://localhost:8000/test-serveur.php

Résultat attendu :

Environnement local PHP opérationnel
