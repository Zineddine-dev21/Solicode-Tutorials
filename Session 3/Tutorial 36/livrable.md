Objectif

Démarrer un serveur Web statique local afin d’afficher la page HTML dans le navigateur et de vérifier automatiquement les modifications apportées aux fichiers HTML et CSS.

Vérification

Le serveur local permet de visualiser le site Web et de constater les changements après l’enregistrement des fichiers.

Remarque

Le serveur local fonctionne uniquement sur mon ordinateur. L’adresse fournie n’est pas directement accessible depuis un autre ordinateur.
