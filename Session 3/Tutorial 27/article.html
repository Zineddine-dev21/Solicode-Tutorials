Introduction

Tailwind CSS est un framework CSS qui permet de créer des interfaces web en utilisant des classes utilitaires.

Pourquoi utiliser Tailwind CSS ?

Il permet de contrôler les espacements, les couleurs, les dimensions et la mise en page directement dans le HTML.
